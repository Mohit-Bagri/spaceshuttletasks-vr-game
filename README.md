  ## About

  Space Shuttle Expo is a VR game built to explore and learn VR development
  mechanics using a space shuttle theme. Players navigate through the interior of
  a space shuttle, completing various interactive tasks to progress through the
  game.

  The game features AI-powered voice guidance that directs players through
  objectives, creating an immersive task-based experience with hands-on VR
  interactions.

  ## Features

  | Feature | Description |

  ## Gameplay

  Players explore the space shuttle interior and complete tasks to progress:

  1. **Start** - Enter the space shuttle environment
  2. **Object Interaction** - Pick up and interact with cubes and other objects
  3. **Waste Disposal** - Dispose small trash items in the bin
  4. **Dismantling** - Use weapons to break apart larger objects
  5. **Particle Collection** - Collect particles and place them to unlock doors
  6. **Hologram Room** - Explore the room with rotating Earth hologram and
  flickering lights
  7. **Climbing** - Climb up to reach the driving room
  8. **Driving** - Take control of the shuttle and navigate to the portal
  9. **Finish** - Reach the portal to complete the game

  ## Installation

  1. Clone the repository
  ```bash
  git clone https://github.com/Mohit-Bagri/spaceshuttletasks-vr-game.git
```
  2. Open the project in Unity (2022.3 or later)
  3. Install required packages:
    - XR Interaction Toolkit
    - Oculus Integration
    - TextMeshPro
  4. Configure build settings for Android (Meta Quest)
  5. Build and deploy to your VR headset
